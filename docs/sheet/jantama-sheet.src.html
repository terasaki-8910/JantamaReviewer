違うと思うものがあれば、番号を最後の自由記入に書いてください。

  1. 検索で古い言葉（「テンパイ」「シャンテン」）を、新しい言葉の別名として受け付けない（言葉をそろえるため）。

  3. README の GIF のウィジェットは、記録の命令をアプリの手前で偽の応答に差し替えて動かした。本物の画面やスクショは撮っていない。
  4. README の写真と GIF を撮る道具は、これまでどおり、撮る間だけ検討画面の窓を開く（1回の起動で1分ほど）。あなたが雀魂を打っている間は動かさない。
  5. 近い役は、v1 のあとの最初の仕事として調べる（実際の局面で計算できるか、どの役を出すか、言い方）。作るかどうかは、見本を見てから決めてもらう。
