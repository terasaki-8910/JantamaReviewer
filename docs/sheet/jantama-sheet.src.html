できたものどう動くか
結びつけの順位と「推定」スクショから読んだ局・残りの牌の数・点数で、その局の判断に順位を付け、1位を「推定」として結びつけます。1位に近い判断は「ほかの候補」に最大4つ出します。推定は保存せず、あなたが選んだもの（選び直したもの）だけを保存します。あなたが選び直した 10月9日 19:09 の半荘を正解として試すと、迷い1〜5 は、あなたの選んだ局面が1位になりました。
読めない画像の読み直し読めなかったときは、画像を濃くしたものと、大きくしたもので読み直します。迷い6 は「東3局・残り38・4,400点」と読めるようになりました。
カードの書き方どのカードも「局・巡目・迷いの種類」「スクショから読んだ値」「推定の印と自分の行動」「ほかの候補」の順にそろえました。読めないときは「スクショを読めませんでした」と出し、局面を手で選びます。
その半荘への取り込み取り込み前の半荘のページの「この半荘に検討結果を取り込む」から取り込めます。mjai の窓は開きますが（Submit と Cloudflare の確認のため）、取り込み先はそのページの半荘に決まっていて、進み具合もそのページに出ます。読んだ局・点数が結果と合わないときは確認を出し、既定のボタンは「やめる」です。
