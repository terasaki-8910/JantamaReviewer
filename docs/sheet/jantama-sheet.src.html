聞かずに決めたこと（14回目）

違うと思うものがあれば、番号を最後の自由記入に書いてください。

  1. 役の名前は漢字にする（「聴牌」「向聴」にそろえたのと同じ。例: 断幺九・混一色・一気通貫）。
  2. 近い役に出すのは、役牌・断幺九・混一色（清一色を含む）・一気通貫・三色同順の5つ。あなたの7半荘の和了69件で、鳴いた和了36件はすべて役牌・断幺九・混一色のどれかだった。対々和・七対子などは出る数が少ないので、最初は出さない。
  3. 近い役は「あと3枚以内、いちばん早い和了より1枚遠回りまで」で、1つの行動に2行まで。
  4. 役無しの警告は、鳴いた手では強く、門前でダマだと役が無い待ちは薄い注にする。立直は役の行に出さず、「門前: 立直・門前清自摸和が使える」「門前を崩す: 立直・門前清自摸和・平和・一盃口が付かなくなる」の薄い1行にする。
  5. 比べる行動の中身が全部同じときは、1つにまとめて出す（見本の場面の約6割）。
  6. 役の判定は自前のコードにし、majiang-core は試験の2つ目の正解に使う（どちらも全部一致したので、替えても正しさは上がらない）。
  7. 打点を出すときも、裏ドラと一発の期待値は足さない（出さないことを画面に書く）。雀魂は切り上げ満貫なしで計算する（実戦の和了69件で確かめた）。
  8. ほかのリポジトリのコードを使うときは、MIT の表示を THIRD_PARTY_NOTICES.md と README に置く。電脳麻将の牌の画像と音は、MIT の対象外なので使わない。
  9. Mac 版でも、雀魂の規約の線は同じ（撮影は押したときだけ、読み取りは対局のあと）。連続で画面を取る仕組みや、ほかのアプリを操作する仕組みは、使わないことを試験で確かめる一覧に足す。
  10. 同期するなら、記録の番号を端末をまたいで一意の id にする。試しで、いまの連番のままでは片方の答えが消えることを確かめた。
  11. ThinkBook に置くサーバーは、sqld ではなく Turso の同期に対応した tursodb にする（置く前に、チャットで内容を確かめる）。
