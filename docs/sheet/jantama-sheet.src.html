ウィジェットの直し（R7-7 の①）

6回目と7回目の要望で直したところです。試す手順は R8-1 にあります。

直したところどう動くか
雀魂が前面でもボタンが届く（R6-2）管理者で動く小さな補助プログラムが、割り当てたボタンだけを拾って本体に知らせます。設定の「管理者の補助プログラムを設定する」を押したときに、1回だけ Windows の確認が出ます。補助プログラムは管理者しか書き換えられない場所（Program Files）に写し、タスクスケジューラに登録します。以後は本体を起動するたびに、確認なしで動きます。
ボタンの登録とテスト（R7-6）「ボタンを登録」を押してから使いたいボタンを押すと、それを覚えます。マウスの中・戻る・進むボタンと F キーなどはそのまま、英字・数字・記号のキーは Ctrl か Alt と組み合わせます。「テスト」の欄は、割り当てたボタンを押すと「受け取りました」と時刻を出すだけで、迷いマークは記録しません。
音の切り替えウィジェットとタスクトレイの右クリックのメニューに「音を鳴らす」を足しました。設定の項目と同じもので、次の起動でも保たれます。
評価のときのスクショ（R7-3）〇△✕ を押したときにも雀魂の窓を撮ります。取り込みのとき（対局後）に、どの局の評価かを画像から読むのに使います。
空の半荘を作らない（7回目の補足）半荘は最初の記録で始まり、「新しい半荘」は今の半荘を閉じるだけです。最後の記録から30分あいたら、次の記録で新しい半荘になります。アプリを起動し直しても、30分以内で閉じていなければ同じ半荘に続きます。

安全のために確かめていること

補助プログラムは管理者の権限で動くので、入力を知らせる以外の部品（画面を撮る、文字を読む、通信する、ファイルに書く）が入っていないことを、テストで毎回確かめています。例外は設定と解除のための1つのファイルだけで、写すことと登録のために、ファイルとタスクスケジューラを扱います。

私が中身を読んで、守りを2つ足しました。補助プログラムは、登録できるボタン以外（文字のキー単独など）の割り当てを受け付けません。また、ほかのプログラムが本体のふりをしてつないできても、補助プログラムの権限は使えません。どちらもテストで確かめています。

できないこと

検討画面が前面にある間は、キーの割り当てでは迷いマークを記録しません。Windows の側の事情で、その間は本体のキーボードのフックに入力が届かないためです。マウスのボタンは効きます。雀魂やほかの窓が前面なら、キーも効きます。

補助プログラムを私が作り直したときは、もう一度「管理者の補助プログラムを設定する」を押してもらう必要があります（Program Files の写しは、自動では新しくなりません）。そのときはシートで知らせます。

聞かずに決めたこと（8回目）

違うと思うものがあれば、番号を最後の自由記入に書いてください。

  1. R7-6（ボタンの登録とテスト）は未回答だったので、サンプルどおりに作った。R8-1 で試せる。
  2. 今のデータにある空の半荘のフォルダ（2つ）は、一覧に出さないだけで、消さない。
  3. マウスの戻る・進むボタンは、検討画面の行き来には使わない。迷いマークのボタンと重なるため。行き来は画面の ← → と Alt+← / Alt+→ で行う。
  4. 削除の確認の「削除」ボタンは赤にせず、黒で目立たせる。赤は「自分の打牌」の印に使っているため。
  5. 選んだ半荘が絞り込みで見えなくなったら、選択から外す。見えていないものを消さないため。「◯件を選択中」の左のチェックで、見えている半荘をまとめて選べる。
  6. 解いた問題がある半荘を消すときは、確認に「解いた問題 N問と、その解き直しの予定も消えます」と足す。
  7. 迷いマークは、スクショから読んだ局の中で、残りの牌の数がいちばん近い判断に結びつける。同じ近さの判断が複数あれば、候補として出して選んでもらう。どの迷いも、あとから手で選び直せる。
  8. 取り込んだ検討結果は、まだ結果の無い半荘のうち、スクショから読んだ局と点数が合うものに結びつける。合うものが無いか2つ以上あるときは、一覧から選んでもらう。迷いも評価も押さなかった半荘の結果は、新しい半荘として取り込む。
  9. 文字の読み取りのテストには、迷いマークのスクショのうち、画面中央の局・残り枚数・点数の部分だけを切り出した画像を使う。プレイヤー名は入らない。
