調べたこと

  • 3回目の表の「一致の度合い」は一致率ではなく、選んだ手の確率を AI の1位の確率で割った値の平均でした。ほぼ同じ判断には部分点が付く数え方です（説明が足りませんでした）。この数え方を、下では「確率の比」と呼びます。
  • Mortal の Rating の式を、検討ツールのソース（mjai-reviewer の src/review/mortal.rs）で確かめました。判断ごとに、AI と同じなら1点、違えば「選んだ手の評価値が、その場の候補の最低から最高までのどの位置か」を0〜1で点にし、その平均を2乗します。保存した結果で計算し直すと半荘全体で 86.7 になり、サイトの値と一致しました。
  • 作者はサイトの注記と FAQ で、Rating は目安にすぎず誤解されやすいこと、AI の1位以外の評価値は正確でないことを書いています。

一致率は、ほぼ同点でも違えば0です。Rating は、候補の多い打牌では最低の候補が基準になるので点が甘く、2択では少しでも違えば0点になります。確率の比は、打牌でも2択でも同じ物差しで部分点になります。物差しの幅は Mortal の温度（0.1）で決まりますが、設定を毎回同じにしているので一定です。

聞かずに決めたこと（4回目）

違うと思うものがあれば、番号を最後の自由記入に書いてください。

  1. 点数と一緒に、その局の5%未満のミスの数も並べて出す。点数だけだと、どこが悪かったか分からないため。
  2. 半荘全体には、mjai のサイトと同じ Rating も参考の数字として出す。
  3. S+〜D への当てはめは、点数が高いほど評価が下がらない形にする。MAKA と食い違った局には印を付ける。
  4. 送ってもらった結果の URL は、サイト側で消える前にすぐ取得して保存する。
