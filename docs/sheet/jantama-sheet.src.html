  1. Mac のデータの保存先の既定は、ホームの直下の ~/JantamaReviewerData（Windows と同じ名前・同じ置き方。Finder で見える）。設定のファイルだけは Mac の決まりの場所（~/Library/Application Support/…）に置く。
  2. Mac のショートカット: 元に戻す Cmd+Z、やり直す Cmd+Shift+Z、検索 Cmd+K、全部選ぶ Cmd+A、戻る・進む Cmd+[・Cmd+]（Option+←→ は入力欄の単語の移動なので使わない）、検索の一覧の先頭・末尾 Cmd+↑・Cmd+↓。表示は「Cmd+K」のように文字で書く（記号の ⌘ は絵文字の禁止に当たるため）。
  3. Mac のメニューバーは日本語で、アプリのメニュー・編集・ウインドウだけ。言葉は Mac の言い方（カット・ペースト）。Windows にはメニューバーを足さない。
  4. Mac へのリポジトリの運び方は、main の git bundle のファイル（push しない）。
  5. majiang-core は、エンジンの1つのファイル（majiang-adapter.ts）だけが読み込む実行時の依存にした。エンジンの純粋さの試験に、その1つだけの例外を書いた。許諾の表示（THIRD_PARTY_NOTICES.md）には、majiang-core と、符の数え方を移した Python の mahjong の2つを書く。
  6. 待ちと打点: リーチの判断では、実戦・AI の印は、切った牌が分かるときだけ付ける（自分の印は付けない）。待ちも点も形もフリテンも同じ打牌は1つの表にまとめる。表は8つまでで、残りは「ほか {n} 通りの切り方は省略しています」。自分の手と副露で4枚使っている牌は待ちにしない。点数は本場・供託を除く。
  7. 同期の競合: 行ごとに、手元・同期用の DB・前回の状態の3つを比べる。両方が直したら、更新の時刻が新しいほう（同じ時刻なら端末名の大きいほう）。消した印は直しに勝つ（消したのを見たあとに作り直したものは残る）。新しい端末の既定の設定は、すでにある設定を上書きしない。
  8. 同期: 一度に20件以上かつ半分以上が消えるときは、止めて「要確認」にし、「削除をそのまま同期する」を押したときだけ通す。ほかの端末で半荘が消えたら、その半荘のフォルダを trash/ に移す（元に戻せる）。
