違うと思うものがあれば、番号を最後の自由記入に書いてください。

  1. 同じ局に 〇△✕ を押し直したとき（手がかりが無い余分な評価）は、あとに押したものを残す。
  2. スクショが読めず、前後の評価・迷いからも局が決まらない迷いは、いままでどおり手で選ぶカードにする。
  3. 説明のアイコンにしたのは「…を押すと…」の説明4つ。次にやることを伝える文は、文のまま出す。
  4. 局の評価の表は、カードの下のまま（迷いの札からカードへ上に移る）。
  5. 「迷い（13）」の数は迷いマークの数のまま。迷いマークの無い迷いのメモは数えず、カードの並びの最後に別に置く。
  6. 通して見る画面でメモを書けるのは迷いの場面だけ（大きな不一致だけの場面には欄を出さない）。答えの「理由（1行）」と区別するため、この欄の名前は「理由」。
  7. 答え合わせのあとのメモには、推定で結びついた迷いのメモも出す（選び直せば、選んだほうに替わる）。
  8. 検討ログの「答えを出す」は、画面を移っても残り、起動し直すと切に戻す。
  9. 検討ログの手牌には副露も出す。ドラの強調は付けない。
  10. 検討ログの行は、いまの出題の画面で開く（見本の専用の画面は作らない）。空の形の「絞り込みを解除」は、期間も「すべて」に戻す。
  11. 幅640px 未満では、アイコンの列をやめて引き出しだけにした。
  12. Home・End の既定のために、設定ファイルに版の番号を足した（前の版のファイルでは、空の局の頭・終わりに新しい既定を入れ、この版からは空なら「外した」と読む）。
  13. 迷いマークの無い迷いのメモは、見本どおり、取り込む前の半荘でも局・本場・巡目を手で入れて足せるように直す。取り込んだあとは、その巡目の自分の判断が1つなら自動で結びつけ、2つ以上ならカードで選ぶ。
  14. README の画面写真の撮り直しと、動く GIF（R11-3）は、v1 を仕上げたときにまとめて作る。
  15. 週の集計の数え方: 答えた局面は、保存した答え1件（出題でも解き直しでも）。評価は半荘を始めた週、迷いマークは押した週、半荘の数は結果を取り込んだ半荘を始めた週で数える。ごみ箱の半荘と、結果を読めない半荘は数えない。迷いマークの「うち答えたもの」は、その迷いの問題に答えが1つでもあるもの。
  16. 一致率の「一致」は、自分の 〇△✕ と AI 基準が同じ帯にあること（〇＝S+〜A-、△＝B+〜B-、✕＝C+〜E）。ずれは「自分 − AI 基準」（〇3・△2・✕1 として数える）。局の評価の表の旗と同じ帯から出し、別の決まりは作らない。
  17. 局面の種類は、承認された見本どおり今週の表だけにする（推移の線は付けない）。仕様書の「件数と推移」は、この形に直した。
  18. MAKA の見込みの「34%」などは AI の確率ではないので、出題の画面に確率を出さない決まり（U-1）とはぶつからない。
  19. 週の成績と来週の重点は、答えと同じ SQLite のファイルに、週の月曜の日付ごとに保存する。
  20. 書き出しには「今日の出題」の組も入れる（入れないと、読み込んだあとに今日の組が作り直される）。ごみ箱の半荘は書き出さない。
  21. 読み込みは置き換えなので、ファイルに無い半荘（この保存先にはある）の記録は消える（確認の文のとおり）。
  22. 検討画面が前面に戻ったとき、半荘の一覧を読み直す（半荘のフォルダを写して戻ったとき、すぐ一覧に出るように）。
